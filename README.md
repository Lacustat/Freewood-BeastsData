### Was ist das?
Startdaten für das Freewood-Wildtier-Archiv: rund 300 Tiere (aus dem Addon Tamed von moody, MIT-Lizenz). Reine Daten, kein eigener Reiter.

### Funktionen
- Wird von Freewood-Beasts automatisch geladen, wenn der Ordner vorhanden ist.
- Eigene Beobachtungen gehen immer vor.

### Abhängigkeiten
- Benötigt: –
- Optional: Freewood-Beasts (lädt die Daten)

### Befehle
Keine eigenen Befehle.

### Installation
Den Ordner `Freewood-BeastsData` nach `World of Warcraft\_forever_\Interface\AddOns\` kopieren. Neue Dateien lädt das Spiel erst nach einem kompletten Neustart; ein `/reload` genügt nur, wenn sich bestehende Dateien geändert haben. Fehler sichtbar machen: `/console scriptErrors 1`, danach `/reload`.

## English

### What is it?
Starter data for the Freewood beast archive: about 300 beasts (from the addon Tamed by moody, MIT license). Pure data, no tab of its own.

### Features
- Loaded by Freewood-Beasts automatically when the folder is present.
- Your own observations always win.

### Dependencies
- Required: –
- Optional: Freewood-Beasts (lädt die Daten)

### Commands
No commands of its own.

### Installation
Copy the folder `Freewood-BeastsData` to `World of Warcraft\_forever_\Interface\AddOns\`. New files only load after a full game restart; a `/reload` is enough only when existing files changed. To see errors: `/console scriptErrors 1`, then `/reload`.
